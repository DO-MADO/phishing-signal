# 무엇을 검증했고 무엇이 남았나

피싱 신호등의 판정은 안전 보증이 아닙니다. 아래 수치는 **2026년 9월 20일 출시된 c3_v2 epoch3와 고정 정책**의 평가·배포 기록을 다시 집계한 결과입니다. 실제 사용자의 연락 전체에서 측정한 정확도나 피해 예방 효과가 아닙니다.

## 1. 피싱 판정 품질

| 확인 항목 | 기록된 결과 |
|---|---:|
| 고정 205개 평가의 최종 정답 | **165 / 205 · 80.49%** |
| 위험 입력을 Safe로 분류 | 11건 |
| 정보가 부족한 입력을 Safe로 분류 | 6건 |
| 정상 입력에 경고 | 9 / 100건 |
| 사전에 정한 절대 안전 게이트 | **FAIL** |

오류 항목은 중요한 잔여 오류의 일부이며 전체 오판을 빠짐없이 나눈 표는 아닙니다. 개발용 450개에서도 정상 경고가 허용 기준을 넘었습니다(`5 > 4`). 과거 205개 평가의 `48.78% · FAIL` 기록도 보존되어 있습니다.

현재 공개 저장소와 체험 서비스는 구현한 기능, 설계 결정, 검증 결과를 확인할 수 있도록 공개했습니다. **공개·배포는 품질 게이트 통과를 뜻하지 않습니다.** 실제 피해 감소 효과와 상용 서비스로서의 안전성은 검증하지 못했습니다.

제품은 모델이 Safe를 반환해도 송금·보안정보 전달·앱 설치 같은 행동을 추가로 확인하고 이미 행동했다면 분석 완료 전에 대응 방법을 보여줍니다. **이 기능들은 오판 가능성을 고려한 설계이지, 위의 미탐을 해소했거나 안전성을 입증했다는 근거가 아닙니다.**

<br>

### 평가를 읽는 범위

- 이 공개 요약만으로 최신 205개의 작성·검수 방식이나 독립성을 입증하지 않으므로 외부 독립 검증 또는 실사용 성능이라고 부르지 않습니다.
- 최신 평가가 현실의 표현과 상황을 얼마나 대표하는지는 이 공개 집계만으로 확인할 수 없습니다. 결과를 실제 수신 연락 전체의 탐지율로 일반화하지 않습니다.
- 이미 개발자가 관찰한 사례는 회귀 확인용입니다. 다시 맞혔다고 새로운 일반화 성능의 근거가 되지 않습니다.
- 과거의 94.4%, 97.35%, 81.95%와 이번 80.49%는 표본·모델·정책·라벨 기준이 다릅니다. 하나의 성능 상승 그래프로 연결하거나 최고 점수를 현재 서비스 정확도로 제시하지 않습니다.

## 2. 학습 모델과 브라우저 실행물이 같은가

개발용 **450개 입력**에서 PyTorch 기준 출력, 변환한 ONNX, Chromium의 ONNX Runtime Web 실행 결과를 대조했습니다.

| 확인 항목 | 기록된 결과 |
|---|---:|
| 브라우저 기본·최종 라벨 일치 | 450 / 450 |
| 브라우저 기술 실패 | 0건 |
| 선택 ONNX의 PyTorch 대비 최대 logits 절대차 | 0.010628 |
| 브라우저의 PyTorch 대비 최대 logits 절대차 | 0.010637 |

**변환·실행의 동일성 검사**입니다. 동일한 오판도 일치할 수 있으므로 피싱 탐지 정확도 100%를 뜻하지 않습니다. 모델은 가중치를 FP16으로 저장하고 FP32로 연산하며 실행 파일은 222,877,586 bytes입니다.

## 3. 실제 서비스 실행 확인

2026년 9월 20일, Chromium 152 데스크톱의 한 환경에서 공개 서비스의 클릭부터 결과 표시까지 측정했습니다.

| 조건 | 관측값 |
|---|---:|
| 첫 분석: 모델 다운로드·SHA 검증·실행 준비·추론 포함 | 29.94초 |
| 같은 탭에서 준비된 실행기를 사용한 후속 분석 | 1.01초 |

각 조건의 **단일 관측값**입니다. 평균·상위 백분위 응답 시간이나 모든 기기의 속도 보증이 아닙니다. 모바일 검증은 당시 실행하지 않았습니다.

배포 전에는 제품 관련 선택 테스트 149개와 규칙 안정성 테스트 603개, 타입 검사와 프로덕션 빌드가 통과했습니다. 운영 데스크톱에서는 실제 모델 로딩, Safe 이후 행동 확인, 근거가 있는 Safe→Hold 보정, 인증번호 마스킹, 실패·재시도, 모델과 독립적인 긴급 대응을 확인했습니다. 실제 전화·신고는 실행하지 않았습니다. 테스트 통과 역시 판정 정확도 측정을 대신하지 않습니다.
