# 소개·신뢰 화면 개선

[← 제품 소개](../README.md) · [서비스 소개](https://www.phishing-signal.site/) · [신뢰와 데이터](https://www.phishing-signal.site/trust)

2026년 10월 8일, 피싱 신호등의 서비스 소개와 데이터 안내를 새로 구성했습니다. 연락 확인은 별도 화면으로 옮겨 바로 입력할 수 있게 했습니다. 이름과 기존 제품의 세 칸 신호는 유지합니다.

## 실제 연락 확인의 흐름으로 소개합니다

소개 화면에서는 같은 합성 연락을 화면에 남기고, 스크롤에 따라 위험 신호와 다음 행동이 펼쳐집니다. 아래에서는 세 신호의 뜻과 배송 안내 예시의 행동 확인을 살펴볼 수 있습니다.

이 장면은 **설명용 화면**입니다. 실제 모델을 실행한 결과나 성능 평가 자료로 제시하지 않습니다. 실제 분석은 [연락 확인](https://www.phishing-signal.site/check)에서 이용합니다.

## 신뢰는 처리 범위를 확인할 수 있게 합니다

어두운 톤의 신뢰 화면에서는 연락 원문과 브라우저 경계를 유지한 채 분석 도구가 들어오는 과정을 보여줍니다. 원문의 브라우저 내부 분석과 모델 다운로드·사례 조회·이용 통계를 구분하고, 필요한 연결과 브라우저 저장 범위를 본문에서 설명합니다.

모델의 위험 탐지 한계와 발신자·거래의 안전을 인증하지 않는다는 점도 함께 안내합니다. 이번 변경은 기존 모델이나 임계값, 데이터 수집 정책을 바꾸지 않습니다. [기존 평가 결과와 한계](evaluation.md)는 그대로 유지됩니다.

## 필요한 기능으로 바로 들어갑니다

| 목적 | 화면 |
| --- | --- |
| 서비스의 역할 이해 | [서비스 소개](https://www.phishing-signal.site/) |
| 받은 문자·메시지 확인 | [연락 확인](https://www.phishing-signal.site/check) |
| 원문 처리와 통신 범위 확인 | [신뢰와 데이터](https://www.phishing-signal.site/trust) |
| 공유 사례 살펴보기 | [사례 동향](https://www.phishing-signal.site/trends) |
| 이미 한 행동에 대한 대응 | [긴급 대응](https://www.phishing-signal.site/check?screen=incident) |

연락 확인에 들어가면 자동 인트로나 안내가 입력을 막지 않습니다. 사용 안내는 필요할 때 다시 열 수 있습니다. 기존 `/?screen=incident` 링크도 긴급 대응으로 이어집니다.

## 모바일과 모션

- 모바일에서도 소개를 다 읽거나 메뉴를 열지 않고 긴급 대응에 들어갈 수 있습니다.
- 작은 세로 화면은 글자를 줄이기보다 제목과 여백을 조정합니다. 매우 낮은 화면과 가로 화면에서는 정적 설명을 제공합니다.
- 화면 모션을 줄이는 선택과 기기의 모션 감소 설정을 지원합니다. 현재 탭의 모션 선택을 유지하고 본문에서 바꿀 때 읽던 위치를 보존합니다.
- 설명 본문은 JavaScript 실행 전에도 읽을 수 있으며 본문 바로가기와 키보드 탐색을 제공합니다.

## 확인한 범위

관련 회귀 테스트 110개, 타입 검사와 프로덕션 빌드를 통과했습니다. 데스크톱 브라우저의 모바일 뷰포트에서 320·360px 너비와 580–641px 높이 조합으로 소개·신뢰 장면 120개 지점을 확인했습니다. 12개 화면 크기에서 데이터 안내 링크의 실제 좌표 탭, 본문 바로가기와 키보드 이동도 확인했습니다.

운영 반영 후 소개·신뢰·연락 확인·사례 동향과 기존 긴급 대응 링크의 정상 응답을 확인했습니다. 320×600에서 소개·신뢰의 끝 장면과 데이터 본문 링크를 다시 확인했고, 배송 안내 합성 예시의 실제 분석과 ‘모르겠어요’ 선택 후 행동 보류 안내도 확인했습니다.

이 기록은 화면과 탐색의 검증입니다. 모델 성능 평가나 모든 기기의 품질 보증을 뜻하지 않습니다. 실제 iPhone Safari·Android의 주소창 변화, 터치 관성·프레임률, OS 모션 감소와 확대 글꼴은 후속 확인 대상으로 남아 있습니다.

기존 시연 가이드의 화면 캡처는 2026년 9월 20일의 운영 화면입니다. 이번 소개·신뢰 화면의 스크린샷으로 대체하거나 새 촬영 자료로 표시하지 않았습니다.
